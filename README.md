This program is a simple python based program that searches an existing excel spreadsheet for tutors (and prints all their wards) and student register no.'s (and prints their name and tutor details).

A basic frontend was built using html + css frontend and js + flask library to use existing python backend to get meaningful results, on Oct 12 6:07 PM. However, since it is in a very basic state, much more is expected to bring it to a usable state.
